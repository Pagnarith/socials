# CapCut config pack — Homework Palette first promo

CapCut has **no remote API** we can push settings into. This folder is the practical substitute: import-ready files + one-time Pro prefs.

## Files

| File | Use in CapCut |
|------|----------------|
| [`first-promo.srt`](first-promo.srt) | Timed KM+EN captions (import on **Desktop / Web**) |
| [`first-promo-tts-en.txt`](first-promo-tts-en.txt) | Paste into **Text-to-speech** (English VO) |

Filming brief: [`../first-promo-video.md`](../first-promo-video.md)

---

## One-time CapCut Pro preferences

Set these once so every new project starts closer to our export target.

### Desktop (recommended for this pack)

1. **Settings → Preferences** (or account gear)
2. Default export: **1080p**, **30 fps**, high bitrate
3. Sign in with the same account as mobile (cloud drafts)
4. Confirm **Pro** is active (no watermark on export)

### Mobile

1. Profile → Settings → **Export resolution** → 1080p when available
2. Turn off watermark (Pro)
3. Link TikTok / Instagram only if you post from CapCut; otherwise export → post in each app

## Project setup (with these files)

1. Film per [`../first-promo-video.md`](../first-promo-video.md) (hook + screen + poster).
2. Open **CapCut Desktop** → New project → **9:16**.
3. Import clips; trim to **30–45s** (lock the edit first).
4. **Captions → Add captions / Import** → choose `first-promo.srt` (UTF-8).
   - Official help: [How do I import subtitles?](https://www.capcut.com/help/how-to-import-subtitles)
5. Style all captions once (select all / apply style):
   - Bold, large
   - White + dark stroke
   - Position: **middle** of frame (not bottom 15%)
6. Optional: Audio → Text-to-speech → paste `first-promo-tts-en.txt` → generate → duck music under VO.
7. End card: poster still 1.5–2s.
8. Export `HomeworkPalette-first-promo.mp4`.

### If you only use CapCut Mobile

SRT import is **not** reliable on mobile. Either:

- Edit captions on **Desktop/Web**, then open the cloud draft on phone, **or**
- Copy each line from the SRT by hand into Text overlays (same timings as the brief).

---

## After captions are styled (save time next video)

1. Select a caption → save as **favorite / default text style** if your CapCut build allows.
2. Duplicate this project for the next Reel; replace the screen clip only; nudge SRT times if the new take is longer/shorter.

### If timings drift

Your take may not match the template exactly. After import:

- Stretch/shrink each caption block on the timeline to match cuts, **or**
- Edit the `.srt` times in any text editor and re-import.

Template assumes: hook 0–3s, grade 3–12s, library 12–25s, features 25–35s, CTA 35–45s. If you skip the features beat, delete cue **4** and start the CTA earlier.
