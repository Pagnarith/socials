# Financial Plan — Homework Palette (Apple App Store)

**Product:** Homework Palette (iPhone & iPad) · App Store id [6801068446](https://apps.apple.com/app/id6801068446)  
**Publisher:** Chakriya · Site: https://homework.chakriya.net/  
**Model:** Free library + optional **Palette Pro** subscription (in-app quizzes)

This replaces the old Minecraft Marketplace / Rhino plugin plan. Primary product revenue is **App Store**, not digital asset marketplaces.

---

## North-star metrics

| Metric | Why it matters |
|--------|----------------|
| App Store downloads | Top-of-funnel acquisition |
| Weekly active families | Product habit |
| Palette Pro trial → paid | Monetization health |
| Social → App Store CTR | Content ROI |
| Support / donation | Secondary only |

---

## Revenue streams

### 1. App Store (primary)

| Source | Notes |
|--------|--------|
| Free downloads | Library, print, builder, read-aloud, lesson recorder stay free |
| Palette Pro subscriptions | In-app quizzes, scores, progress — Apple IAP |

Track in App Store Connect: units, proceeds, active subscriptions, churn.

### 2. Social recognition (acquisition engine)

YouTube ads, TikTok Creativity, Facebook in-stream, sponsorships — used to **grow downloads**, not as the core product P&L.

### 3. Community support (optional)

Buy Me a Coffee, GitHub Sponsors, Patreon, Super Chat — keep free tools sustainable; never block the free library.

---

## Unit economics (directional)

```
Social post / demo
  → App Store visit
  → Install (free)
  → Use library / recorder
  → Need quizzes → Palette Pro
```

- **CAC:** mostly organic social time + occasional ads  
- **LTV:** Palette Pro months retained × Apple net proceeds  
- Free features exist to earn trust with parents; Pro is the paid unlock
